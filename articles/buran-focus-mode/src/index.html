Buran focus mode

This page declares <meta name="buran-focus"> and links a web app manifest. In a browser that understands the pair, it can be promoted to a full-screen "focus site" and launched from a widget.

What the manifest supplies

  • short_name — the label under the icon
  • start_url — what launching opens
  • scope — where the app ends
  • icons — the tile artwork
  • theme_color, background_color — chrome and splash
