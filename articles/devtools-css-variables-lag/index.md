[Открыть демку](demo/index.html)

Демка генерирует страницу с настраиваемым числом CSS-переменных на `:root`
(по умолчанию **1000**) и DOM-элементов (по умолчанию **2000**).
Параметры можно передать в URL: `demo/index.html?vars=5000&nodes=2000`.
